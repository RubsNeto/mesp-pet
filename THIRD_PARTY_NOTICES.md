# Third-party source

The island state machine, easing/spring helpers and canvas motion engine in
`src/coucou` are adapted from [Coucou by Louis-CFM](https://github.com/Louis-CFM/coucou),
under its MIT source-code license. The original license is retained at
`src/coucou/LICENSE`.

This application uses MESP's own procedural sprites. It does not redistribute
the Mochi character, Coucou artwork, sounds, branding or promotional media.

The remaining project is based on [MESP Pet](https://github.com/RubsNeto/mesp-pet).
